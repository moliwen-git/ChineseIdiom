# 成语复习小工具 · 设计文档

- 日期：2026-09-26
- 作者：CC - AI 助理
- 状态：已与主人确认方案，待实施
- 用途：新加坡南洋女子中学 中一高级华文 成语复习（80 个成语）

## 1. 背景与目标

主人在 `input/` 文件夹提供了 4 份 Word 考卷（成语练习 1-20、21-40、41-60、61-80），
每册 20 个成语。考试题型为**选择填空**。目标是一个可以随时打开复习的小工具：

1. 能查看每个成语的解释和用法（例句）；
2. 能通过选择填空题练习、测试自己，做错的题可以反复重练。

## 2. 数据源盘点

| 考卷 | 成语列表 | 第一大题（看释义选成语） | 第二大题（例句填成语） |
|---|---|---|---|
| 1-20 | ✅ 20 个 | ✅ 附答案（成语 + 释义） | ✅ 答案内嵌在句子空格处 |
| 21-40 | ✅ 20 个 | ✅ 附答案 | ✅ 答案内嵌在句子空格处 |
| 41-60 | ✅ 20 个 | ⚠️ 只有释义，无答案 | ⚠️ 只有例句，空格空白 |
| 61-80 | ✅ 20 个 | ⚠️ 只有释义，无答案 | ⚠️ 只有例句，空格空白 |

**41-80 两套的答案配对策略**：每册恰好 20 个成语、20 道释义题、20 道例句题，
由 cc 依据释义内容和句子语义做一对一配对；配对结果**先整理成清单请主人抽查确认**，
确认后才写入题库。

## 3. 总体架构

### 3.1 文件结构

```
ChineseIdiom/
├── index.html      ← 复习工具主页面（双击浏览器打开即用）
├── data.js         ← 题库文件（主人以后只改这个文件即可增删成语）
├── docs/           ← 设计文档等
├── input/          ← 原始 Word 考卷（保留不动）
└── extracted/      ← 从 docx 提取的文本（中间产物）
```

### 3.2 题库加载方式：`data.js` 而非 `data.json`

需求：整个文件夹拷到**任何电脑**上，双击 `index.html` 就能用，且只改题库文件。

- 浏览器安全策略禁止 `file://` 页面用 `fetch` 读取本地 JSON（CORS 拦截），
  纯 `.json` 方案必须依赖本地服务器，换电脑即失效 → **否决**。
- `<script src="data.js">` 加载本地 JS 在 `file://` 下是允许的 → **采用**。
- `data.js` 内容 = 首行 `window.IDIOM_DATA = ` + 标准 JSON + 结尾 `;`，
  其余部分与纯 JSON 文件完全一致，主人编辑体验不变。
- 将来若要部署上线（如 GitHub Pages），此方案无需任何改动。

### 3.3 数据 Schema（data.js 内的 JSON 结构）

```jsonc
{
  "meta": { "title": "中一高级华文 成语复习", "version": "1.0" },
  "books": [
    { "id": "b1", "name": "成语练习（1-20）" }
    // …共 4 册
  ],
  "idioms": [
    {
      "id": 1,                    // 1-80，对应考卷编号
      "book": "b1",               // 所属册
      "idiom": "爱屋及乌",
      "meaning": "比喻因喜欢某个人，连带着也喜欢跟这个人有关的人或物。",
      "sentences": [
        {
          "text": "小梅的男朋友是足球队员，____，她也爱看足球比赛了。",
          "source": "original"    // original=原卷例句 | new=cc 新编例句
        }
        // 每个成语恰好 3 句：1 original + 2 new
      ]
    }
    // …共 80 个
  ]
}
```

约定：
- 例句中空格统一用 `____`（四个下划线）表示，位置即成语填入处；
- 释义题直接取 `meaning` 字段作题干；
- 正确答案永远是该条目的 `idiom`，不单独存储，避免数据不一致。

## 4. 题库内容规格

- **80 个成语**，每个包含：
  - 释义 1 条（来自原卷第一大题）→ **释义题 80 道**；
  - 例句 3 句 = 原卷例句 1 句 + cc 新编例句 2 句 → **例句题 240 道**；
- 合计 **320 道选择题**。
- **新编例句要求**（主人明确指定）：
  - 难度对标新加坡南洋女中**中一高级华文**考试水平；
  - 场景贴近新加坡中小学生生活：学校/CCA/小贩中心/组屋/地铁/邻里/节庆等；
  - 句子语境必须足以唯一确定该成语（不能几个成语都通）；
  - 不与原卷例句重复、同一成语的 3 句之间场景不雷同。
- **干扰选项生成规则**：从**同册**其他 19 个成语中随机抽 3 个；
  同册不足时（不会发生，兜底逻辑）从全库抽。选项顺序每次随机打乱。

## 5. 功能设计（三个模式）

### 5.1 📖 学习模式

- 成语卡片列表：大号成语 + 释义 + 3 条例句（原卷例句标注「原卷」，新句标注「新编」）；
- 可按册筛选（全部 / 1-20 / 21-40 / 41-60 / 61-80）；
- 支持按成语关键字搜索。

### 5.2 ✏️ 练习模式（核心）

每轮流程：

1. **抽 10 个成语**，权重规则（高→低）：
   - 错题本中该成语的未掌握题（加权重现，主人要求「时不时把错误的成语再拿来考」）；
   - 从未考过的成语（保证多练几轮后覆盖全部 80 个）;
   - 最近考过且答对的成语排最后（避免短期重复）。
2. 每个成语从它的 4 道题（1 释义 + 3 例句）中**随机抽 1 道**出题；
3. 四选一，选中后立即判定：
   - 对 → 绿色反馈；
   - 错 → 红色反馈 + 显示正确答案 + 显示该成语释义和例句（现场复习）；
4. 该成语的题答错 → 记入错题本；答对且它在错题本中 → 计数减一，
   连续答对 2 次 → 移出错题本（掌握）；
5. 10 题答完 → 本轮总结页：得分、错题回顾（成语 + 释义 + 正确例句）、
   「再来一轮」按钮。

### 5.3 🔥 错题本模式

- 列出所有未掌握的错题（题目、我的错误答案、正确答案、释义）；
- 「专刷错题」按钮：只从错题本抽题练习（不足 10 题则全出）；
- 可一键清空错题本。

### 5.4 进度存储（localStorage）

| 键 | 内容 |
|---|---|
| `idiom.wrong` | 错题本：`{ 题目标识: { idiomId, qType, qIndex, myAnswer, wrongCount, correctStreak, lastSeen } }` |
| `idiom.history` | 每个成语的练习记录：`{ idiomId: { asked, correct, lastAskedAt } }` |
| `idiom.settings` | 界面偏好（如上次选择的册筛选） |

- 题目标识规则：释义题 `m-{idiomId}`；例句题 `s-{idiomId}-{0|1|2}`；
- ⚠️ 已知限制（已向主人说明）：localStorage 绑定「本机本浏览器」，
  换电脑时工具与题库完全可用，但错题本/练习记录不跟随；
- 所有读取包 try/catch 并做数据校验，损坏或为空时以默认值启动，页面不崩。

## 6. 界面与体验

- 单文件 `index.html`，无外部网络依赖（字体、样式、脚本全部内联/系统字体），离线可用；
- 浅色系专业风，结构化、层次化：顶部模式切换标签（学习 / 练习 / 错题本），
  主区域随模式切换；
- 移动端自适应（手机浏览器也能复习），桌面端最大宽度居中；
- 简体中文界面；成语与例句使用适合阅读的衬线/无衬线中文字体栈。

## 7. 错误处理

| 场景 | 行为 |
|---|---|
| `data.js` 缺失或语法错误 | 页面显示友好提示「题库加载失败，请检查 data.js 是否存在且格式正确」，不白屏 |
| `IDIOM_DATA` 结构缺字段 | 启动时校验（80 成语、每个 3 句、字段齐全），列出具体问题 |
| localStorage 不可用/损坏 | 降级为「本次会话内存记录」，提示进度不会被保存 |
