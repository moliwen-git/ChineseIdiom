## 1. 背景与目标

主人在 `input/` 文件夹提供了 4 份 Word 考卷（成语练习 1-20、21-40、41-60、61-80），
每册 20 个成语。考试题型为选择填空。目标是一个可以随时打开复习的小工具：

1. **成语复习**：翻转卡片记成语和解释；
2. **成语测试**：拖拽成语填入例句空格，即时判分、看正确答案，可无限重来，
   错过的成语会优先再考，直到学生自己选择不再尝试为止。

## 2. 数据源盘点

| 考卷 | 成语列表 | 第一大题（释义） | 第二大题（例句） |
|---|---|---|---|
| 1-20 | ✅ 20 个 | ✅ 附答案（成语 + 释义） | ✅ 答案内嵌在句子空格处 |
| 21-40 | ✅ 20 个 | ✅ 附答案 | ✅ 答案内嵌在句子空格处 |
| 41-60 | ✅ 20 个 | ⚠️ 只有释义，无答案 | ⚠️ 只有例句，空格空白 |
| 61-80 | ✅ 20 个 | ⚠️ 只有释义，无答案 | ⚠️ 只有例句，空格空白 |

**41-80 两套的答案配对策略**：每册恰好 20 个成语、20 条释义、20 道例句题，
由 cc 依据释义内容和句子语义做一对一配对；配对结果**先整理成清单
（`docs/idiom-pairing-review.md`）请主人抽查确认**，确认后才写入题库。

## 3. 总体架构

### 3.1 文件结构

```
ChineseIdiom/
├── 成语学习小助手.html   ← 唯一工具文件（双击打开；内含两个视图：成语复习 / 成语测试）
├── data.js               ← 题库文件（主人以后只改这个文件即可增删成语）
├── tools/                ← 数据管线与校验脚本（构建期使用）
├── docs/                 ← 设计文档、配对清单、实施计划
├── input/                ← 原始 Word 考卷（保留不动）
└── extracted/            ← 从 docx 提取的文本（中间产物）
```

单 HTML 文件内部以顶部标签切换两个视图，样式（`<style>`）与脚本（`<script>`）
全部内联；页面只通过 `<script src="data.js">` 读取题库。整个文件夹拷到任何电脑，
双击「成语学习小助手.html」即可使用，无网络依赖。

### 3.2 题库加载方式：`data.js` 而非 `data.json`

需求：整个文件夹拷到**任何电脑**上，双击就能用，且主人只改题库文件。

- 浏览器安全策略禁止 `file://` 页面用 `fetch` 读取本地 JSON（CORS 拦截），
  纯 `.json` 方案必须依赖本地服务器，换电脑即失效 → **否决**。
- `<script src="data.js">` 加载本地 JS 在 `file://` 下是允许的 → **采用**。
- `data.js` 内容 = 首行 `window.IDIOM_DATA = ` + 标准 JSON + 结尾 `;`，
  其余部分与纯 JSON 文件完全一致，主人编辑体验不变。
- 将来若要部署上线（如 GitHub Pages），此方案无需任何改动。

### 3.3 数据 Schema（data.js 内的 JSON 结构）

```jsonc
{
  "meta": { "title": "中一高级华文 成语复习", "version": "3.0" },
  "books": [
    { "id": "b1", "name": "成语练习（1-20）" }
    // …共 4 册
  ],
  "idioms": [
    {
      "id": 1,                    // 1-80，对应考卷编号
      "book": "b1",               // 所属册
      "idiom": "爱屋及乌",
      "meaning": "比喻因喜欢某个人，连带着也喜欢跟这个人有关的人或物。",
      "sentences": [
        {
          "text": "小梅的男朋友是足球队员，____，她也爱看足球比赛了。",
          "source": "original"    // original=原卷例句 | new=cc 新编例句
        }
        // 每个成语恰好 3 句：1 original + 2 new
      ]
    }
    // …共 80 个
  ]
}
```

约定：
- 例句中空格统一用 `____`（四个下划线）表示，位置即成语填入处；
- 正确答案永远是该条目的 `idiom` 字段，不单独存储，避免数据不一致。

## 4. 题库内容规格

- **80 个成语**，每个包含：
  - 释义 1 条（来自原卷第一大题）→ 用于复习卡片背面；
  - 例句 3 句 = 原卷例句 1 句 + cc 新编例句 2 句 → 测试视图每轮从 3 句中随机抽 1 句；
- **新编例句要求**（主人明确指定）：
  - 难度对标新加坡南洋女中**中一高级华文**考试水平；
  - 场景贴近新加坡中小学生生活：学校/CCA/小贩中心/组屋/地铁/邻里/节庆等；
  - 句子语境必须足以唯一确定该成语（不能几个成语都通）；
  - 不与原卷例句重复、同一成语的 3 句之间场景不雷同；
  - 句长与复杂度参照原卷例句（10-45 字为宜）。
- 例句总量 240 句，保证多轮测试同一成语也常换常新。

## 5. 功能设计（单文件 · 两个视图）

顶部标签：**📖 成语复习** / **✏️ 成语测试**，点击切换，互不丢状态。

### 5.1 📖 成语复习视图（翻转卡片）

- **卡片正面**：大号成语；**点击卡片 3D 翻转** → **背面：解释**（主人确认：只放解释，不带例句）；
- 卡片网格布局，一屏多张；每张卡独立翻转；
- 按册筛选（全部 / 1-20 / 21-40 / 41-60 / 61-80）+ 成语关键字搜索；
- 「全部翻回正面」按钮，方便自测：先看成语回想解释，再逐张翻开验证。

### 5.2 ✏️ 成语测试视图（拖拽填空，核心）

**每轮流程**：

1. **抽 10 个成语**，权重规则（高→低）：
   - 上一轮/历史拖错的成语优先重现（主人确认保留），直到**连对 2 次**视为掌握；
   - 从未考过的成语其次（保证多轮之后覆盖全部 80 个）；
   - 最近考过且答对的成语排最后（避免短期重复）。
2. 每个成语从它的 3 条例句中**随机抽 1 句**，共 10 句例句，`____` 处为可放置的空格；
3. **候选区**：正好这 10 个成语，做成可拖动的「成语块」，顺序随机打乱
   （主人确认：一一对应，不加干扰项）；
4. **交互**（桌面 + 触屏双兼容）：
   - 桌面：鼠标拖拽成语块放入空格；已放入的可点击退回候选区；
   - 触屏：点选成语块 → 点空格放入（再点已放入的空格退回）；
5. **「上交答案」按钮**：10 个空格都放入成语后才可点击（未放完时置灰并提示还差几个）；
6. **上交后判分显示**：
   - 每句标注 ✅ / ❌；错的句子显示正确成语 + 该成语解释；
   - 顶部显示本轮得分（如 7/10）；
   - 页面锁定，不可再改动答案；
7. **「再一次尝试」按钮**：清空重来，按步骤 1 的权重**随机生成另外 10 道题**；
   可无限循环，直到学生自己不想练为止。

### 5.3 练习记录（localStorage，内置于抽题算法）

| 键 | 内容 |
|---|---|
| `idiom.progress` | `{ byIdiom: { idiomId: { asked, correct, correctStreak, wrongLast, lastAskedAt } } }`，驱动抽题权重 |
| `idiom.settings` | 界面偏好（上次的视图、复习页册筛选、累计轮数） |

- 掌握判定：`correctStreak >= 2` 的成语不再享受错题优先权；
- ⚠️ 已知限制（已向主人说明）：localStorage 绑定「本机本浏览器」，
  换电脑时工具与题库完全可用，但练习记录不跟随；
- 所有读取包 try/catch 并做校验，损坏或为空时以默认值启动，页面不崩。

## 6. 界面与体验

- 单 HTML 文件，样式脚本全部内联，无外部网络依赖（字体用系统字体栈）；
- 浅色系专业风，结构化、层次化、卡片化；
- 移动端自适应（手机浏览器也能复习和点选式测试），桌面端最大宽度 1080px 居中；
- 卡片翻转用 CSS 3D transform；拖拽用 Pointer Events 统一实现
  （同一套代码兼容鼠标和触摸，移动超过 8px 判定为拖拽，否则判定为点选）；
- 简体中文界面；工具名「成语学习小助手」用作 `<title>` 和页面顶部大标题。

## 7. 错误处理

| 场景 | 行为 |
|---|---|
| `data.js` 缺失或语法错误 | 页面显示友好提示「题库加载失败，请检查 data.js 是否存在且格式正确」，不白屏 |
| `IDIOM_DATA` 结构缺字段 | 启动时校验（成语数、每个 3 句、字段齐全），列出具体问题 |
| localStorage 不可用/损坏 | 降级为「本次会话内存记录」，提示进度不会被保存 |
| 成语总数 < 10（主人将来删减题库） | 每轮题量自动降为 min(10, 成语总数)，不报错 |
